# Política de Privacidade do FinApp

Última atualização: 3 de agosto de 2026.

O FinApp trata dados de conta (nome e e-mail), dados financeiros inseridos pelo usuário e, opcionalmente, foto de perfil. Esses dados são usados para autenticação, gerenciamento da conta, personalização do perfil e fornecimento das funções de organização financeira do aplicativo.

Os dados são transmitidos por conexão criptografada e armazenados no Supabase com autenticação e políticas de acesso por usuário e casa. A foto de perfil é opcional e, quando enviada, é disponibilizada por uma URL pública não listada; portanto, o usuário não deve escolher uma imagem que contenha informações sensíveis.

Ao importar um extrato CSV, o arquivo é lido para preparar e revisar os lançamentos. O arquivo original não é armazenado pelo FinApp; somente os lançamentos confirmados pelo usuário são enviados e armazenados.

O FinApp não utiliza publicidade, rastreamento entre aplicativos nem SDK de análise de uso. Não vendemos dados pessoais. Prestadores de infraestrutura podem processar dados somente para autenticar usuários, armazenar dados e operar o serviço.

O usuário pode executar a exclusão da conta no aplicativo em **Perfil → Excluir minha conta** ou solicitá-la pela [página de exclusão de conta]({{ '/exclusao-de-conta/' | relative_url }}). A exclusão remove a conta e os dados associados, incluindo a foto de perfil, ressalvadas retenções exigidas por lei.
